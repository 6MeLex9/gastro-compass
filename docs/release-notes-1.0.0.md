# ГастроКомпас 1.0.0

Android-приложение для людей с **ГЭРБ, гастритом, язвенной болезнью, СРК, ЖКБ и хроническим
панкреатитом**: дневник питания, который не просто считает калории, а предупреждает обострения.

## Что внутри

**Умные подсказки о рисках.** 24 фактора × 13 диагнозов + контекст приёма (время, приём натощак,
накопленный за день жир, текущие симптомы, объём порции). Для каждого продукта — балл риска 0–100,
объяснение механизма действия, безопасные замены и максимальный безопасный вес порции.
Жёсткие запреты (например, алкоголь при ГЭРБ) выделены отдельно.

**Калории и КБЖУ с безопасными границами.** Расчёт по Миффлину–Сан Жеору с поправкой на диагноз:
дефицит не более 20% (15% при ЖКБ и панкреатите), «пол» калорийности, лимиты жира, насыщенных
жиров, сахара, соли, кофеина и клетчатки. 12 автоматических проверок дня, план приёмов пищи,
памятки «как снижать калории без обострений» и «как безопасно добрать вес».

**КБЖУ по этикетке — 8 вариантов, 5 уже работают.** Разбор вставленного текста этикетки
(кДж → ккал, «на 100 г / на порцию / на упаковку», «в т.ч. насыщенные», «следы», соль из натрия,
проверка по формуле 4/9/4, уверенность распознавания), ручной ввод по таблице, калькулятор блюда
с учётом ужарки и уварки, пересчёт «упаковка → порция», оценка риска по составу продукта.
В планах — фото этикетки (OCR), штрихкод и голосовой ввод.

**Персональные закономерности.** Приложение сравнивает, как часто симптомы появлялись после
продуктов с определённым фактором, с фоновой частотой, и показывает личные триггеры с числами —
например: «симптомы в 6 случаях из 7 (86%), в среднем — 22%».

**Ещё:** 238 продуктов в офлайн-справочнике, 9 экранов, аналитика за 14 дней, журнал симптомов,
история взвешиваний, недельная корректировка нормы по тренду веса, экспорт дневника в JSON.

## Приватность

Приложение **не запрашивает доступ в интернет**: нет аккаунтов, рекламы, аналитики и передачи
данных. Всё хранится только на устройстве, удаляется одной кнопкой.

## Установка

1. Скачайте файл `GastroCompass-debug.apk` из вложений ниже.
2. Откройте его на телефоне и разрешите установку из неизвестных источников для того приложения,
   из которого открываете файл.
3. Play Protect может предупредить («Неизвестное приложение») — это нормально для сборки,
   подписанной отладочным ключом. Нажмите «Всё равно установить».

**Требования:** Android 7.0 и новее (minSdk 24). APK универсальный — нативных библиотек внутри нет,
поэтому подходит под любой процессор (ARM, ARM64, x86).

**Контрольная сумма SHA-256:**
```
990B83A76DA1C841159AA21F3EF9740A6B8ED2711D634FBAB2B3106E4377A795
```

## Что проверено

55 unit-тестов (разбор этикеток, риск-движок, расчёт калорий) — все проходят.
Прогон на эмуляторе Pixel 3a, Android 15: онбординг, дневник, подсказки, аналитика, профиль

## Дисклеймер

ГастроКомпас — помощник в соблюдении диеты и наблюдении за состоянием. Приложение **не является
медицинским изделием**, не ставит диагноз, не назначает лечение и не заменяет консультацию врача.
При затруднённом глотании, необъяснимой потере веса, крови в стуле или рвоте, ночных болях
и боли в груди — обратитесь за медицинской помощью немедленно.
