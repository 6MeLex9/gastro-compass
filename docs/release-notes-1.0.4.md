# ГастроКомпас 1.0.4

Три изменения по вашим замечаниям: учёт выпитой воды, отдельная кнопка для неё
и центральная кнопка добавления еды вместо «Подсказок» в нижней панели.

## 1. Учёт выпитой воды

На главном экране появилась карточка **«Вода за день»**:

- показывает, сколько выпито **относительно личного лимита**: «250 / 2355 мл»
  с полосой прогресса и подписью, сколько осталось;
- лимит берётся из вашей настройки (*Профиль → Режим питания → Лимит воды*),
  по умолчанию — автоматический (30 мл на кг массы тела);
- подсказка: пить лучше между приёмами пищи, а не во время еды (правило при ГЭРБ).

Вода хранится в отдельном журнале — приложение ничего не путает с едой, и записи
переживают перезапуск. В «Дневнике» за день тоже видна строка «Вода», а в «Анализе» —
среднее потребление за неделю.

## 2. Отдельная кнопка добавления воды

В той же карточке — быстрые кнопки **+150 / +200 / +250 / +300 / +500 мл**,
кнопка **«Другой объём»** (точный ввод + пилюли 100/250/500/750 мл)
и **«Отменить последнее»** на случай ошибки.

## 3. Центральная кнопка добавления еды

Нижняя панель теперь такая: **Сегодня · Дневник · ⊕ Еда · Подсказки · Профиль**.

По центру — заметная круглая кнопка **«Еда»**: она открывает экран добавления продукта
поверх текущего (стрелка «назад» возвращает туда, откуда вы пришли). Это подчёркивает
главную цель приложения — быстрый подсчёт калорий с учётом безопасности для ЖКТ.

«Подсказки» остались отдельной вкладкой (слева от «Профиля»), а «Анализ» открывается
с главного экрана кнопкой «Анализ» в «Быстрых действиях».

## Как обновить

Установите APK поверх текущей версии — все данные (дневник, вода, профиль) сохранятся.

## Требования

Android 7.0 и новее. Интернет не нужен — приложение работает полностью офлайн.

## Проверено

67 unit-тестов (без провалов). На эмуляторе Pixel 3a, Android 15: вода сохраняется
после перезапуска (250 мл не пропали), центральная кнопка открывает «Добавить продукт»
с полем поиска и категориями.
